# TabInfo

**Works in:** Teams · Copilot · Outlook

Represents information about the iFrame content, rendered in the collab stage popout window.

## Schema

| Name | Type | Default | Description | In version |
| --- | --- | --- | --- | --- |
| `contentUrl` | `string` | — | The URL to open in an iFrame. | — |
| `entityId` | `string` | — | The unique entity id for this content (e.g., random UUID). | — |
| `name` | `string` | — | The name for the content. This will be displayed as the title of the window hosting the iFrame. | — |
| `websiteUrl` | `string` | — | An optional website URL to the content, allowing users to open this content in the browser (if they prefer). | — |
